# Font files (Acumin Pro)

Place your Acumin Pro `.woff2` files here so the site can use them:

- `AcuminPro-Regular.woff2` (weight 400)
- `AcuminPro-Semibold.woff2` (weight 600)
- `AcuminPro-Bold.woff2` (weight 700)
- `AcuminPro-Italic.woff2` (weight 400, italic)

You can export these from Adobe Fonts (if you have a subscription) or use the font files from your licensed copy of Acumin Pro. The site will fall back to system fonts until these files are present.
