# GEMINI Project Context

## Directory Overview

This directory is an [Obsidian](https://obsidian.md/) vault that serves as a personal knowledge management system (a "second brain") and the source for a personal website generated with [Quartz](https://quartz.jzhao.xyz/).

The content is written in Markdown and organized into a folder structure that separates different types of notes and content.

## Key Files and Directories

*   `index.md`: The main landing page of the website and the vault.
*   `bio.md`: A biography page.
*   `Daily/`: Contains daily notes, useful for journaling and tracking activities.
*   `Inbox/`: A folder for capturing quick, fleeting thoughts and ideas before they are processed and organized.
*   `Literature/`: For notes on articles, books, and other external resources.
*   `Notes/`: Holds permanent, atomic notes on various topics, forming the core of the "second brain".
*   `Projects/`: To organize notes and materials related to specific projects.
*   `Areas/`: For notes on broad areas of life and work.
*   `Blog/`: Contains blog posts for the personal website.
*   `Attachments/`: A directory for storing images, PDFs, and other attachments.
*   `Page_Templates/`: Contains templates for different types of notes, which can be used in Obsidian to maintain a consistent structure.
    *   `Daily Note.md`: A template for daily notes.
    *   `Literature Note.md`: A template for literature notes.
    *   `Permanent Note.md`: A template for permanent notes.
*   `.obsidian/`: This directory contains Obsidian-specific settings for the vault.
    *   `community-plugins.json`: Lists the installed community plugins (`terminal`, `calendar`).

## Usage

This directory is intended to be used as a vault in the Obsidian application. You can create, edit, and link notes using the Obsidian interface.

The structure is designed to support a Zettelkasten-like workflow for knowledge management. New ideas can be quickly captured in the `Inbox`, developed from literature in the `Literature` folder, and then formalized into `Notes`.

The content is also used to generate a personal website with Quartz. The `Blog`, `Notes`, and `Projects` folders are likely to be the main content published on the website.
